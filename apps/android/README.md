# DazeDev Mobile

Native Android companion for DazeDev. Connect SSH/tmux hosts, browse shared workspaces, open an interactive terminal, and prepare editable speech drafts on the phone. Each host has its own connection and trusted-key store.

Build from this directory with `./gradlew lintDebug testDebugUnitTest assembleDebug assembleRelease`. Requirements: JDK 17 or newer, Android SDK/build tools 36, and `npm --prefix apps/desktop ci` from the repository root. Gradle stages the canonical host helper, xterm bundle and generated DazeDev logo. `assembleRelease` signs with a key you supply as environment variables or Gradle properties: `DAZEDEV_RELEASE_STORE_FILE`, `DAZEDEV_RELEASE_STORE_PASSWORD`, `DAZEDEV_RELEASE_KEY_ALIAS` and `DAZEDEV_RELEASE_KEY_PASSWORD`. Without them the release build stops. Never commit a keystore. Release APKs are shrunk, not debuggable and contain arm64-v8a code only.

Use `python3 scripts/check-local.py --fixture-python /path/to/venv/bin/python` with a disposable environment containing Paramiko 5.0.0 to run all SSH fixture tests; with this script a missing fixture fails instead of skipping. The fixtures use their own tmux and browser bridge folders and a throwaway release key. No production accounts or keys are needed. JVM tests use Android's own org.json implementation (the AOSP `android-json` artifact), so JSON parsing and output match the phone. Device UI and voice measurements need a real phone or usable emulator.

Application ID: `com.adamchesters.dazedev.mobile`. It installs alongside the former app; it cannot read another application's private settings. Passwords are not saved. A private key you pick is read once and stored in the app's private storage, encrypted with a key held in Android Keystore; profiles from older versions move to this storage after their next connect. Its passphrase is saved the same way only if you turn on Remember passphrase. Remove this host deletes the host's stored key, saved passphrase and known host keys. Check server fingerprints before trusting them. A changed host key is refused; forget the old key under Host keys only if you know the server key was replaced. Hosts need Python 3.9 or newer and tmux. Windows-local sessions need a separate bridge.

Moonshine English Medium Streaming stays local after preparation. First use downloads about 269 MB with consent. Model files are checked against pinned sizes and SHA-256 once, then by a saved size and time record; damaged caches can be repaired during preparation. An interrupted download resumes where the server allows it. The model stays loaded while a terminal is open. Tap Voice in a terminal to open the draft and start listening. Tap End to stop and edit, or Enter to finish listening, submit the prompt and press Return. A successful submission clears and closes the draft, returning to the terminal. Failed submissions keep the draft open. Clipboard Paste only inserts text. No remote transcription fallback is configured. End waits for the final words and releases the microphone; backgrounding cancels capture. Drafts and originals stay on this device, have a Clear control, and inactive entries expire after seven days.

Terminal cards show their target host before you open them. If a host is not configured on this phone, its connection form opens with any saved non-secret details. Older workspace entries may require an SSH address. Saved Tailscale SSH targets reconnect on tap when tailnet access permits; the saved host identity is verified before opening the terminal. Plain SSH over Tailscale uses its configured SSH authentication method.

Keep hosts connected in the background (off by default) keeps SSH connections open while the app is in the background, with a low-priority notification that shows how many hosts are connected and offers Disconnect all. On Android 13 and later the app asks to show that notification; the connections stay open even if you decline. With stored credentials or Tailscale SSH, a dropped connection is retried three times before the host shows Disconnected. When the phone loses its network, connected hosts show Disconnected at once; with this setting on, hosts that need no typed secret show "Waiting for the network" and reconnect with the same retries when a network returns. If Android ends the app in the background, reopening it shows the same host, folder and terminal; the terminal waits for Reconnect because connections do not survive.

Terminal size decides which device sets a tmux window's size. Follow this phone resizes the window for every attached device while the phone is active. Keep the other devices' size leaves desktop windows as they are (tmux 3.2 or newer). Opening the on-screen keyboard never resizes the window; the view scrolls to keep the cursor visible.

Dragging a terminal scrolls it. With tmux mouse on, drags become mouse-wheel scrolls, as on desktop; turn tmux mouse on in Settings to scroll full-screen apps. Rotation and short app switches keep the terminal; after two minutes in the background it detaches. Links that a host opens ask first. Private screen blocks screenshots and the Recents preview.

Updates: the app checks public `android/v*` GitHub releases once a day. Download fetches the APK inside the app, checks its SHA-256 against the release's `SHA256SUMS` asset, then hands it to the Android package installer (you confirm there, and Android asks once to allow installs from DazeDev). If `SHA256SUMS` is missing, does not list the APK or does not match, the app refuses and deletes the file. Open release page stays available as a manual fallback. Each Android release must therefore attach `SHA256SUMS` with a line `<sha256>  DazeDev-Mobile-<version>.apk`.

Built with AndroidX/Compose, JSch, xterm.js and Moonshine. Full notices are available offline in Licenses and credits.

Device tests for the terminal: `TerminalBridgeDeviceTest` checks the WebView message channel in both directions, drag-to-wheel routing with and without tmux mouse tracking, the extra keys (Esc, one-shot Ctrl) and keyboard text through the WebView input connection. Run `./gradlew connectedDebugAndroidTest` with a phone or emulator attached; the local check only compiles them (`assembleDebugAndroidTest`).

Device-only voice tests never download models. Build `./gradlew assembleDebugAndroidTest`, install the debug app and test APK, then run `MoonshineDeviceTest#modelManifest` with AndroidJUnitRunner to inspect the pinned runtime's download manifest. After separately preparing and verifying the model, run `MoonshineDeviceTest#offlineInferenceWithExplicitlyStagedFixture` with `modelDirectory` and `pcmFixture` arguments. The fixture must be at most ten seconds of 16 kHz mono signed 16-bit PCM; optional `expectedPhrase` checks its transcription. Disable device networking to verify installed inference. The result records load/inference times and final PSS, not a thermal or peak-memory qualification.
